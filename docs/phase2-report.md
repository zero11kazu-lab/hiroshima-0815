## 座標・縮尺

東を+X、上を+Y、南を+Zとする。人体・建築の局所寸法は1unit=1m。**街区間の地理的距離は15分の1に圧縮**した。高さは同率圧縮していないため、実寸都市・GIS精密復元ではない。歩行2.9unit/s、走行5.51unit/s、既存の時計10倍を維持した。

地上基準は島病院直下。公表値34°23′41″N、132°27′17″E（S01）を記録し、ゲーム上は(-15,-110)。公表測地系は未確定のため、これを精密WGS84測量値とは称さない。爆発高度は600mを記録（S01/S02）。画面への方向投影には圧縮した40unitを使用する。

`historicalOffset(p) = ((p.x+15)*15, (p.z+110)*15)` はこの模式舞台の換算。一般建物の被害傾向に用いる推定距離であり、実在地点の測量ではない。公共建築は資料上の距離を別に保持。一雄開始点の換算距離は約2.19km、マサミ投下前は約1.01km。8:15は開始地点へ戻さず、その時点の実際のプレイヤー位置を保存する。

## 3D品質の変更

- 汎用建物34棟＋専用公共建築3棟。使用バリエーションは木造住宅8、商店6、長屋3、倉庫2、公共建築3。汎用19種は寸法・材質・窓・庇・小屋根などを共有形状から組み合わせる方式。全種が個別の精密建築モデルではない。
- 切妻屋根、瓦模様、軒、縁台、基礎、柱、格子、雨戸・引き戸、店舗のれん、長屋の複数戸口、倉庫扉・一部煙突を追加。
- 256pxの共有生成テクスチャ：木、漆喰、土壁、瓦、石、土、砂利、焦げ、水。外部画像の利用なし。通常物体は軽いLambert、水面のみStandardMaterial。水面は模様の微移動で、実反射や水シミュレーションは行わない。
- 電柱の腕木・碍子、電線、橋の欄干、簡易接地影。新たなリアルタイム影マップは使わない。
- NPCは球状の頭、近距離の目・鼻、襟、帯、帽子、和装風の裾を共有インスタンスに追加。歩行・会話の既存制御を継承。一雄にも顔・襟・ボタンを追加。
- 炎は距離により5組から2組の共有ビルボードへ切替。煙は角ばった塊から共有ぼかしテクスチャのビルボードへ変更。実際の煙ゾーンと連動した低い煙を描画。最寄り火源だけ1灯の局所照明を使用。

## 投下後・ゲーム進行

道路・川・橋・基礎位置は投下前後で共通。北側近距離では木造のDESTROYED/COLLAPSEDを多く、南側では部分残存を増やす。公共RC模型は残存外殻を優先する。1500m/2000mの帯と被害確率は**ゲーム調整値**で、史料の個別被害図を再現した数値ではない。樹木も一律消去せず、南部の一部は折損幹を残す。

被害の外形には板、柱、瓦片、壁片、基礎、焦げ材質を使用。火災は覚醒後の時間圧縮を含む舞台演出であり、「08:15にその全地点が同時に燃えた」という表現上の史実主張ではない。炎・煙・HP・熱・スタミナのバランス式は試作11を維持。32〜34火源の検証ケースで迂回可能な道を確保した（実際の数は覚醒位置と経路保護により変化）。

進行は既存通り：投下前の届け物 → 聞き込み → 8:15 → 覚醒 → 子どもの捜索と母親への報告 → 給水と男性の確認 → マサミ再配置 → 再会 → 脱出 → 30日後 → 急性放射線症説明 → 和室 → 別れ → 【完】。

再配置先は選定した北側区域内に限定し、追加火災後もマサミ足元の熱22未満・煙0.08以下を確認する。最終エリアの半壊遮蔽と迂回路、近距離かつ視線が通った場合だけの再会判定を維持した。移植で見つかった、通行人がプレイヤーの接触距離から抜け出せないケースも修正した。

## 負荷・検証

同じ844×390表示、同じ3地点での描画比較（Chromium/SwiftShader、実機FPSではない）：

|地点|試作11 draw calls / triangles|フェーズ2 draw calls / triangles|
|---|---:|---:|
|(0,10)|230 / 12,706|237 / 20,414|
|(0,35)|327 / 16,518|265 / 22,122|
|(26,-22)|117 / 9,016|115 / 14,480|

モデル形状が増え、三角形・テクスチャ数は増加。draw callは同程度の範囲。共有マテリアル、建物ごとの結合、近距離だけの細部、遠距離カリング、NPCインスタンス、炎・煙LOD、既存の低FPS時の解像度/距離低下を使用。瞬間的なGPU負荷・発熱・長時間電池消費はこの比較だけでは保証できない。

確認済み：

- 通常時計による8:15発火1回、閃光→遅延音→爆風→覚醒の順序。
- 実移動・環境ダメージ有効で、投下前の用事、2ミッション、マサミ探索を完了。自動操作の一例では再会時HP約84.5。
- 【完】まで全11エンディング状態を順に確認。ストーリー本文・曲の管理は継承。
- タッチ入力エミュレーションでスティック＋走るを同時操作。1秒歩行2.90、走行5.51、走行後スタミナ84。離指・スタミナ0の歩行復帰。
- カメラは11,424位置/角度ケースで障害物内侵入0、完全遮蔽0、人物見切れ0。追加した軒先装飾の近接時透過を調整。
- 火災の重複区域では約2.87秒でHP0となるケースを確認。一瞬の接触で即死する設定ではない。安全な迂回経路は別に検証。
- 投下後/エンディング音楽の音声出力を測定。AudioContext running、両方で非ゼロ出力・ピーク1未満。
- ミッション順序ガード、話すボタン、死亡時の確認操作、チェックポイント復帰、マサミの二重再配置防止。

**iPhone Safari実機はこの環境に接続されておらず未検証。** モバイル寸法・タッチイベントはChromiumで確認した。実機でのGPU速度、Safari固有の音声再開、発熱時性能は、実機の最終受入確認が必要。

- NPC、聞き込み、ミッション配置、被害描画、カメラの移植箇所を調整。音楽、HP計算、ミッション状態順、エンディング本文は維持。
- `tests/phase2-*.cjs`：今回の回帰確認。開発環境専用で、プレイヤー側の操作は不要。

今後効果が大きい順：1945年地図の主要街路・河岸を実測ベクトル化 → 公共建築の写真に基づく外形修正 → 電車曲線・停留所位置 → 屋根の寄棟/入母屋と街路幅の差 → 人物の身体シルエット → 時刻別火災範囲。まずiPhone実機の負荷測定を基準に、細部の追加量を決める。
