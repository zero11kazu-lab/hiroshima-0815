# V1.4 レール・舗装軌道の微調整

基準コミット: 9f7f0e3。既存V1.4専用Siteのみ更新。Version 1.0〜1.3に変更なし。

## 原因
`districtGround`がtram道路レコードごとに4本の`LineSegments`を生成。複線2組なので4本自体はデバッグ線ではない。線の高さ.26に対し路面は.015で、24.5cm上に浮いていた。レール横位置±.7/±1.7に対し、車輪は車体中心1.2±.76=.44/1.96で各26cmのずれ。横線は東西tram-miyuki道路のレールで、道路継ぎ目ではない。道路表面はもともと交差部重複を除去済み、変更なし。

## 修正
- 既存複線の中心±1.2を維持し、各線を左右2本の金属頭部・内側の溝に変更。レール中心間1.52、頭部幅.085、内法軌間1.435。人物/局所寸法1unit=1mと既存車輪寸法に合わせたゲーム模型値。
- 地面上端.04（道路より2.5cm）、溝底.026、底.017。Lambertで鏡面反射なし、テクスチャ追加なし。
- 追加道路レコードが接する地点では同一縦列を統合し、重複端部を作らない。東西の既存接続部は道路内の16分割の曲線でつなぐ。南北の直進経路も維持。交差部の同じ高さの上面は凸多角形差分で重複を除く。枕木や不必要な横断線は追加しない。
- 御幸橋は既存の橋面上端.24に合わせ、レール上端.265へ。橋端の短い接続で上下をつなぎ、道路・橋を変更しない。
- 車体形状/窓/色/屋根/車輪ジオメトリを変更せず、車体表示位置だけY=-.22へ。車輪下端がレール.04に一致。架線の座標を維持し、ポールの上端だけ補正して接触を維持。XZ位置・停止位置・当たり判定は不変。
- 投下後は同じジオメトリのまま煤色へ変更。既存の周辺灰・瓦礫・被害設定を維持。RESETで通常色へ戻る。

## 歴史資料の範囲
既存PDFの軌道併用橋・電車通りとS03/S05/S06を継承。PDF・既存JSONに軌間の数値記載は確認できなかった。1.435は車輪と整合する模型内法値として採用したもので、1945年の軌道線形・分岐形状を測量復元したものではない。曲線・細部は既存街区内での創作補完(C)。既存資料PDFは未変更。

## 性能と制限
軌道全体2,221三角形、geometry属性約240KB、1 Mesh。旧ground Line 1個を置換し架線Lineは維持、描画オブジェクト数は増えない。色の切り替えはキャッシュしたマテリアル2状態。ポスト処理・物理演算・毎フレーム処理・追加テクスチャなし。

iPhone実機の見た目/タッチ/FPS/ちらつきは未確認。比較画像は実ゲームの形状・テクスチャをBlenderで描画したオフライン確認。旧Lineだけは比較用に細幅面へ変換しており、Safariのピクセル線幅の厳密な再現ではない。
