# Version 1.4 第4段階 — マットな地面と生活・空気感

基準は第3段階 `cb2f64fbee49e9ff6da46b3421680e8e81c45a59`。独立した既存V1.4作業ブランチ/サイトを使用し、第3段階をGit bundleへ保存した。Version 1.0〜1.3は変更しない。

## 1. 地面の調査と修正

旧版の地面・道路はMeshLambertMaterialで、metalness/roughnessを使うPBR材質ではなく、specular・環境マップ・法線マップ・emissiveもない。真の鏡面反射を設定していたとは確認できなかった。トーンマッピング/ポスト処理も今回の追加ではない。火災のPointLightは既存の距離18mの局所照明であり、変更していない。水面だけに使う別のPBR材質も維持。

確認した見た目上の要因候補:

- 建物跡の床は複数の材質タイルを含む512×256アトラスを参照していた。ミップ時の境界混色を完全に避ける余白ではなく、灰・煤・石などの明暗差を拾う可能性があった。
- 道路の128pxテクスチャには周期的なsinの明暗があり、焼け跡も明るい灰の面と暗い面を重ねていた。
- 床と基礎を同一メッシュにまとめ、面ごとの法線/材質差が強く見える構成だった。

投下前の影と灰面の高さが近い点も調べたが、既存setDistrictMaterialsが正常に投下後の影を隠していた。原因から除外し、重複する影切替は追加していない。作業中の影に関する初期説明を訂正した。

今回の対策:

- 地面専用256×256の連続した土・灰ノイズへ分離し、隣接する材質タイルや周期的な明るい帯を参照しない。
- 床面は1枚の不規則な面へ統合。全頂点の法線は正確に上向き、頂点色は白で統一し、面単位の明暗を持たせない。
- マットな拡散反射材質を継続使用。reflectivity=0、envMap/normalMapなし、不透明/depthWriteあり。焼け跡には深度オフセットも設定。
- 基礎は低い詳細メッシュへ分け、背の高い構造のカメラ用外接箱を拡大させない。近距離の基礎・瓦礫、既存の焼損建物は維持。
- 地面テクスチャの赤チャンネル平均約73、標準偏差約3で、黒一色にはせず、明暗差を抑えた煤・灰色とした。

これらはコード/ジオメトリ上の確認と対策。iPhone実機で同じ視点のギラつきを再現して主因を断定したものではなく、実機での解消確認は未実施。

## 2. 生活小物

6カテゴリ各3組、計18組（東側8、西側10）:

- 木箱
- 小さなバケツ
- 木のたらい
- 竹籠
- 木製腰掛け
- 店先の商品台

投下後は、焼けた板、崩れた箱/台、倒れて損傷した容器へ切替。木・金属・竹の一般的な生活用具を参考にした創作であり、実在住所の個別家財を復元したものではない。confidence/sourceIds/fictionalを設定に保持。S03/S05を既存の街区・建築背景資料として参照し、原本歴史資料PDFは変更していない。

新規設定は `data/environment_finish_v14.json`、描画は `src/environment-finish-v14.js`。街の建物・道路・河川・橋・軌道・樹木を動かさず、建物際に決定的な配置をする。24候補を検査し、6候補を除外して18組を配置。道路・橋・NPC経路・マサミ接近経路・ミッション候補・樹木等を避け、立体小物の外形全体を既存の建物collider内に収めた。壁面より外側の狭い余白を使う小型装飾で、衝突物は追加しない。新しい不可視壁や経路変更はない。

各カテゴリの投下前/後ジオメトリを共有（6+6種類）。既存の建物/焼損アトラスとマテリアルを再利用。28m、低品質時20mで非表示。RESETやタイトル復帰で二重生成しない。

## 3. 光・空気・音

投下前: 空/霞を少し落ち着いた青灰色にし、日光・半球光の色を穏やかな朝色へ調整。光源数、強度、位置、影計算は増やしていない。

投下後: 空/霞をわずかに褐色寄りの灰色へ。霧の開始/終了距離、煙の密度・量・色、火災の照明やダメージは変更していない。画面ぼかし、重いポスト処理、灰粒子等を追加していない。実機での見やすさや探索難易度の体感は未確認。

音は既存AudioManager/AudioContext/ループを使用し、新規音源・録音・悲鳴を追加していない。AMBIENT_MIXのみ以下を微調整:

|---|---:|---:|
|投下前の風|0.12|0.11|
|投下後の風|0.27|0.25|
|鳥|0.10|0.085|

火災音の既存倍率0.5、会話環境音、給水音、足音、崩落音、航空機音、BGMとON/OFFの処理は維持。実際の再生・iPhoneでの聴感は未確認。
