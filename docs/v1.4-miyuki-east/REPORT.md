# V1.4 御幸橋東詰の道路・軌道接続

基準 c85fe3f。東はゲーム内+X、南は+Z。御幸橋中心(50,38)、橋長28/幅6、東端X=64。既存の電車通りはX=0〜66、その先のv11-east-approachはX=66〜86/幅6、v11-east-mainは中心X=86/幅7、Z=35〜79。その南端は既存の横道(Z=79/幅4)に接し、マップ南端81まで道路面がある。マップ範囲はX=-43〜110、Z=-79〜81で変更なし。

## 原因と接続
東側の2道路がtram=falseで、前版ではレールの生成がX=66で終わり、路面もdirt材へ切り替わっていた。橋の路面Y=.24と陸側道路Y=.015の差も残っていた。

- 既存の東側2道路を通常の舗装軌道に統一。新しい道路を街区へ無作為に通したり、橋を追加したりしない。
- X=64〜86を橋から東へ連続させ、X=81付近から既存街路の範囲内の曲線で南へ接続。X=86の街路を南下し、既存横道の南端Z=81（探索範囲の境界）まで続ける。マップ外の新規延長はない。これはひとつの継続経路で、新しい分岐線は追加しない。
- 橋からX=64〜72の8単位で22.5cmを緩やかに下げる。道路上面とレールは同じ高さ関数を使用。橋面=.24、陸側=.015、レール頭部は各面の2.5cm上。道路の側面も土面まで閉じ、浮いた薄板にしない。
- 橋の路面部分は既存のgravel材/UV倍率へ統一し、陸側との材質・色・粒の大きさを合わせる。道路メッシュは橋の床と重なる部分を差し引き、同じ面が重なってちらつかない構造。
- 同じ高さに接する東西道路レコードを統合してレールを生成。元の2線/各線2本（合計4本）を継承。追加の線を重ねない。軌間内法1.435、車輪中心間1.52を維持。
- 架線も同じ左右レールの平均経路を使用し、曲線や接続部で未接続の端を作らない。市電本体・停止位置・車輪の寸法は変更なし。

## 史実と推定の範囲
既存資料S03/S05/S06と歴史考証PDFの御幸橋の軌道併用・街路関係を継承。元の東側街路は個別線形未確認のゲーム用補完(C)。今回の接続・曲線もその範囲内の創作補完で、1945年の軌道を測量復元したものではない。PDF原本は未変更。

## 干渉・既存機能
前後の実メッシュ外形をクリアランス帯で検査し、建物・畑・囲い・小物等の干渉0件。追加の地物移動は不要だった。建物の全geometry/UV、原本WORLD_DATA/NPC_DATA、全樹木位置、すべてのcolliderが前版と一致。NPC合計37人、市役所X=-13.5、車両XZ=(1.2,-55)を維持。移動範囲・NPC経路・ミッション配置・演出・音声のソースは未変更。
