# V1.4 開始地点とイベントの東西バランス

基準17aeffd。東西は既存の御幸橋中心X=50で判定（X>50東、その他西）。UIや画面上の左右ではない。

## 実装
- 新規START/RESET: 既存の被爆前マサミ候補と、原始開始点からの検証済み徒歩経路を再利用。開始候補は東6・西10の16地点。現在のマサミから4m以内の候補を除外してから、側を50/50、側内の地点を抽選。開始履歴を専用キーへ保存し、同じ側の代替地点があれば直前地点を避ける。候補数の差で側の割合を変えない。
- 既存の被爆前マサミ抽選は別システムとして維持。一雄の開始地点だけが毎回変わる。カメラ・入力・速度・衝突判定を変更しない。
- M1依頼側50/50。M2はM1依頼側の反対70%、M3はM2依頼側の反対70%。それぞれ独立した乱数を使う。
- 各ミッションの依頼→目的の反対岸70%を、上記と別に3回抽選。既存のセット候補、順序、依頼者への帰還、負傷者の支援処理を維持。
- まず独立抽選した希望6条件に一致する、互いに干渉しない安全な3セットを探索。成立しない場合のみ、検証済み候補へ緩和し、locationPlan.placementPolicy.fallbacksに希望/採用/理由を記録。完了不可能な座標を作らない。
- M3避難先は既存セットに含まれるものを使用し、避難経路の距離・安全条件は維持。依頼者・負傷者・水源を途中で再抽選しない。
- マサミはM3の実際の依頼側から反対70%の希望側をプラン内部に保持。実際の候補位置は従来どおりM3完了時に、実際の完了位置から選定。直線45m・徒歩経路70m以上、最大240mの既存探索条件を維持。希望側が不可能な場合だけ反対側へ緩和し理由を記録。出現解放/手掛かり/再会/エンディングの仕組みは維持。
- checkpointの既存シリアライズに配置方針も保存される。再開では再抽選しない。タイトル帰還後のSTARTは新規抽選。エンディングA/Bと会話の既存抽選は変更なし。

これは実際のplannerと経路検証を使った1000開始抽選＋1000配置抽選。配置統計は固定された投下後のNPC・地形・起点におけるシミュレーションで、実機1000プレイや1000種類のNPC状態を意味しない。マサミの統計抽選は避難先中心で完了するケース。実プレイの完了位置や周辺NPCにより有効候補と安全フォールバックが変わり得る。
