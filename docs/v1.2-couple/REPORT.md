## 変更

- M1の浮遊物体は `childSmoke`。煙用に追加されていたテクスチャなし `IcosahedronGeometry` が、Y=3.4、scale=(1.1,1.9,1) の多面体として見えていた。生成と再配置処理から除去した。子ども、低い瓦礫、梁、地形、collision、HazardFieldの煙・ダメージは維持。同一M1セットを修正前後で描画して確認。
- M3の依頼・道案内を口語へ修正。HUD用の「〜へ。道を確かめる」をNPCの引用台詞へ流用していた箇所を分離。実際の相対方角・橋の横断有無を使う。受注・支援・避難完了の条件は変更なし。
- 被爆前マサミ: authored 20地点（両岸10ずつ）。独立した配置データ・履歴キーで、START/RESET時に抽選。前回IDを除外し、同一プレイでは移動させない。投下後の抽選・M3完了条件は維持。聞き込みも当回の位置に対応。
- 候補は既存の衝突判定で徒歩経路を検証。事前検証した折れ線経路をデータへ保存し、起動時には経路の再検証だけを行う。起動時の20回のA*探索を避けた。徒歩距離約57.5〜134.1ゲームm。地理・建築配置・縮尺は変更なし。場所はゲーム上の創作。
- 被爆前会話18パターン。最初の9回は日常→軽口→思い出→繰り返し話しかける反応、10回目以降は追加9パターンから前回を除外して抽選。各4〜6台詞（2〜3往復）。既存UIで1台詞ずつ進み、時計を止めず8:15に中断される。
- エンディングA: マサミ死亡・一雄が看取る。B: 一雄死亡・マサミが看取る。開始時に独立した2回の乱数でA/B=50/50と会話番号を選択し、プレイ中・チェックポイント再開で保持。HP・選択肢とは無関係。
- 会話はA5/B5の計10種類。元の会話をA-1として全文・秒数とも保存。直接的な「愛してる」は用いない。
- 本編と同じ人物モデルの室内コピーを使い、患者・付き添いの姿勢、衰弱、胸の呼吸、死亡時の停止、呼びかけ、死亡コメント、悲嘆、独白を役割に対応。室内のみのマテリアルを再利用し、本編の外観を変更しない。
- Aの一雄の既存独白は完全保持。Bはマサミの別の独白。共通の慰霊碑・筆文字【完】・タイトル復帰・BGMは維持。健康影響の説明は患者に対応させ、付き添う側も被曝しており将来が保証されない旨を明記。
- 既存のタイムラインID（MASAMI_DEATH等）は互換性のため維持し、実際の人物はpatient/caregiverの役割で切り替える。強制分岐関数はdebugモードのみ。
