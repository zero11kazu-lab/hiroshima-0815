# V1.4 髪型の中断作業再開と画面回転対応

基準53560a8、ブランチv1.4-building-samples。髪型の変更は未コミットで保持され、公開は配置バランス版だった。差分・テスト・比較画像を保持し、再生成せず継続。旧版へ書き込みなし。

## 回転
旧resizeはコンテナの0サイズを除外せず、setSizeのCSSサイズ書き換えと多発するviewportイベントでバッファを再確保する構造。カメラ側にも独立したリサイズ経路があった。入力が回転をまたぎ、WebGL消失時はstarted=false、復旧時はlast=0のみでゲームが再開しない不具合も存在した。実機の各症状の直接再現は環境上未確認だが、これらのコード上の問題を修正した。

単一のresizeへ統合。有限・非ゼロのゲーム領域を採用し、setSize(...,false)でCSS制御と分離。サイズ変更時だけ再確保し、DPRは既存品質上限と300万画素以下に制限。縦横回転/visualViewport/windowイベントは40msと280msの有限な再確認へ集約。通常フレームのカメラ経路でも最終レイアウトを同期する。FOV・orbit・距離の初期化は行わない。

変化時に入力を解放し、スティック半径も0除算を防止。context復旧で同じrenderer/scene/RAFループを使い、元のstartedへ復帰する。ゲーム状態のresetや追加RAF、AudioContext生成なし。canvasはCSS100%を維持。低い横画面のUIはsafe-areaと112pxスティック/画面内会話領域を使用し、縦画面デザインは維持。

## 髪型
旧女性は頭頂の髪と離れた球状のお団子のみで、後頭部に皮膚色が露出していた。重要人物の髪がheadの兄弟で頭の回転へ追従しない構造も修正。丸みに沿う不透明の髪殻、広い接続部、小さな団子を共通化。額/耳の生え際は残す。マサミは低く小さく整えた差分。通常女性・低いまとめ髪・tuckedの差を維持し、年齢/人数/衣服/顔は不変。

被爆後は同じ髪殻を保持し、団子を数mmずらす・傾ける専用共有geometryと煤色を使用。弱ったマサミ用atlasの肌色の帯を外側の髪で参照しないようUVを限定し、不自然な頭皮色を防止。30日後は通常の整った形状を使う。遠景は共通の簡略髪型でマサミだけ目立たない。

## 検証と性能
女性16人。髪296三角形（近景、共通/マサミ差分）、マサミ全身2430→2516。比較用の近景集計:46バッチ維持、51756→54614三角形(+5.5%)。遠景:8バッチ維持、7104→8416。LOD/共有素材/既存atlasを維持し、新テクスチャ・透明毛束・追加アニメーションなし。

男性/子ども/一雄のgeometry、女性の衣服、男性crowd atlas、NPC_DATA/建物/全colliderが旧版と一致。髪テストは後頭部/頭頂のFrontSideレイ、頭回転追従、有限頂点・UV、共有geometry、A/Bの姿勢・表示、RESETを検証。

viewportテストは6回の縦横切替、0サイズ、同サイズ再確保なし、ゲーム状態不変、同rendererでのcontext復帰を検証。既存camera/return/important/crowd/1000配置抽選/NPC負傷人口/御幸橋/ミッションから再会・A/Bのテストも成功。頭身テストは髪がheadの子になったため顔geometryそのものを測るよう修正。旧髪と同一のハッシュを求めるテストは、意図した置換を確認するよう変更。

DOM/WebGLRenderer/音声はスタブ。実Three.js形状と状態の検証であり、実ブラウザ/実機の回転、UI safe-area、音、FPS・メモリは未確認。画像は同じ照明・視点で実geometry/textureをBlenderで描いた比較（WebGL/Safariスクリーンショットではない）。
