# V1.4 市電屋根修正

基準 a5907ca。屋根上面は6枚の連続面だが、裏・前後端・側縁の面がなく、車体の上桟(上端2.455)と軒(2.51)にも隙間があった。片面描画のため下からは消え、前後から屋根内部が見えた。旧モデルのRaycasterで正面・裏側の欠落を再現。LODや透明マテリアルが原因ではない。

上面座標・外形を保ち、底面2.45と端面・側縁を追加して閉じた低ポリ断面へ変更。投下後は従来の欠損帯を残し、その断面を閉じた。両面描画への切り替えや覆い隠しではなく形状自体の修正。

三角形: 投下前876→916 (+40)、投下後802→840 (+38)。メッシュ2バッチ・マテリアル・テクスチャ・毎フレーム処理は増加なし。新旧で屋根以外の三角形座標、当たり判定、マップ・NPCデータが一致。

テスト: 屋根の閉じた辺、正面・背面・側面・上・裏・斜め・遠方からのFrontSideレイ判定、投下後の欠損、LOD、損傷/RESET、カメラ中央追従、周辺4地点の通行、単一の市電火災を確認。既存landmarks-finish-v14テストと新tram-roof-v14テスト成功。build・JS構文・diff check成功。

比較図は実形状と実テクスチャを使用したBlenderのオフライン描画。ブラウザ/Safariの画面ではない。iPhone実機の見た目・FPSは未確認。描画メッシュ/素材が不変で頂点増分も小さいが、実機性能を保証したとは扱わない。
