## 描画・負荷対策

- 既存の建物単位materialバッチ、共通box/cylinder geometry、256px共通素材・テクスチャを再利用。
- 既存距離カリング・品質自動調整を維持。追加建物の細部表示は30単位以内（既存建物は38のまま）。
- NPCは既存のInstancedMeshと距離別更新へ統合。人数倍増を避けた。
- 火災・煙は既存の固定容量InstancedMesh、遠距離簡略化、空間ハッシュを使用。容量を増やしていない。照明も既存の1灯を再利用。
- 地面は元の145×145面を拡大せず、重ならない東・南タイルを追加。道路は既存の重複面切り分けhelperを使用しZ-fightingを防ぐ。
- 電線は同軸の隣接電柱・最大32単位まで。追加配列の区切りをまたぐ131単位の誤接続を生成しない。旧電線の形状は維持。
- 屋根は修正済み生成関数をそのまま再利用。長い屋根棒の再導入なし。

ローカルChromium/SwiftShader・844×390条件、同じ旧区域3視点で比較した描画時間中央値はV1.0が2.8/1.4/0.5ms、V1.1が1.3/0.9/0.6ms。draw callは265→282, 237→251, 115→145で、視点による増加は残る。面積と同率で描画負荷が倍増する状態ではなかった。詳細 `performance.json`。これはホスト上の限定比較であり、iPhoneのFPSやGPU時間の保証ではない。
