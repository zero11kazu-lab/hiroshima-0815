# V1.4 被爆後NPCの回転と子ども下敷き表現

基準2e4afe3。被爆後の一般NPCが行動半径の外に出ると、毎更新でpostHeadingに1.7ラジアン加算していた。15Hz更新では目標方向が秒間25.5rad変わり得た。回避後の実移動方向とyawも一致せず、混雑時の方向切替がそのまま表示されていた。

行動半径の外では拠点に戻るベクトルを使い、半径の半分まで戻ってから通常の向きへ復帰（ヒステリシス）。目標角の更新は既存5秒周期を維持。一般NPCのyawは実移動方向へ最短角で、最大.9rad/sec（約52度/sec）に制限。ほぼゼロの力・行き詰まりでは.6秒休止し、再試行は既存2.5秒閾値を使用。新しい大規模AIや速度変更なし。初回被爆状態設定時に新しい一時値を初期化。会話時の一般NPCも同じ旋回制御。一雄・マサミ・救助の追従制御を変更しない。

M1の子どもは既存モデルを仰向けへ姿勢変更。頭/胸/腕を外に出し、腰から下の部品は隠して瓦礫を身体が貫通する見た目を避ける。最も低い可視面を地面から2.5cmに合わせる。低LODも同じ寝た姿勢。梁・柱・土壁/屋根片5個を共有材質1メッシュ60三角形へ統合。支持部分を地面から立ち上げ、白い棺桶状オブジェクトは生成しない。

子ども位置は不変。4方向の空き具合を比較し、子どもと瓦礫を同じ角度へ向ける。会話中に全身だけが瓦礫から回転しないよう子どものyawを固定する。顔・胸が瓦礫より外にあり、1.4mの既存判定近傍へ接近できることを東12/西12の全候補24地点で検証。NPC identity・会話・M1進行条件・抽選設定は不変。

検証: 一般NPC11人で各60秒相当の行動更新、最大旋回.9000000000000073rad/sec、±π境界・不正heading回復を確認。全24候補の姿勢/顔位置/接近/RESET検証、既存important、髪型、負傷人口、1000配置抽選、viewport/camera、M1→2→3→マサミ再会→A/B、タイトル復帰テスト成功。旧importantテストの「頭が.64mより高い」という座位前提は、仰向けの頭が瓦礫外にあるかを検証するよう変更。

追加texture・collider・物理演算・NPCはなし。髪型・道路・橋・市電・UI・音声・回転対応・配置確率ソースは未変更（important-peopleの髪型関数は未変更）。姿勢と可視パーツの状態だけを既存rendererへ反映する。

自動検証は実Three.js/経路/ゲーム状態、DOM/WebGLRenderer/音声はスタブ。比較図は実geometry/textureのBlenderオフライン描画で、Safari画面ではない。iPhone実機の挙動・操作・FPSは未確認。build・JS構文・diff checkを実行し、既存V1.4専用Siteのみ更新する。
