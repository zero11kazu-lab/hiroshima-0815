# ミッション配置ランダム化・最終統合確認

最新公開ソース2b9fcdcを基準に、既存の6セット抽選・マサミ探索・男性外観固定・エンディング更新を保持。旧ローカルを元にした別系統の配置処理は採用しない。

MISSION 1: m1-0〜m1-5、6セット。母親＋子ども。
MISSION 2: m2-0〜m2-5、6セット。男性＋破損住宅給水管。
新規プレイのresetでMath.randomからseedを生成し、投下後ワールド生成時に独立したsaltで候補順を決め、現在の火災・壁・NPC・経路・距離条件を満たす組み合わせを選ぶ。同じプレイ中はlocationPlanで固定。チェックポイントはseed・位置・選択IDを保存し、再開で再抽選しない。

前回IDはlocalStorageへ保存。今回、ストレージ禁止時にもページ内メモリで前回IDを保持する補完を既存関数へ統合し、デバッグ時だけ選択IDをconsoleへ出すようにした。別のManager・候補配列・NPCは追加しない。

minimumEventDistance=18。母子距離24〜42、男性と水65〜100、母子経路75以下、水への経路85〜155。熱30以下、煙0.08以下、直接火炎接触なし、会話可能な周囲余白、NPCとの重なり、マサミ候補への後続経路も検査する。マップ・火災・壁を削除せず、既存配置で成立するセットのみ選ぶ。
