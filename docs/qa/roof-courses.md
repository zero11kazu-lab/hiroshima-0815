# 屋根から浮く細長い部材の修正

原因: 汎用木造建物の瓦筋8本が「幅の半分の水平棒」として生成されていた。X位置は屋根の中腹で固定のまま、Yは棟〜軒へ変化し、Zも別に移動していたため、切妻の傾斜面から浮き上がり、屋根外側へ突き出す。

建物全体のbounds・scale、共有geometry、電線の終点に異常な延伸は確認されなかった。修正はWorld.buildBuildingの瓦筋生成ループに限定。細い部材は棟方向（Z）へ走らせ、左右の傾斜面上のX/Yを同じ割合で計算する。棟1本も同じ材質で結合する。長さは屋根奥行きと建物奥行き×1.5の小さい方を上限にする。

切妻本体・軒・柱・建物座標・道路・NPC・ミッション・衝突のコード/データ変更なし。材質単位の既存mergeDetailsを使用し、draw batchは増えない。頂点数は棟の箱1本分のみ増加。共有geometryは変更しない。

node tests/roof-courses.cjs成功。HEADの旧HTMLと修正版を同じブラウザで比較。37棟の座標と屋根本体geometry、全衝突データ、全Line/LineSegments頂点が完全一致。汎用建物34棟の瓦筋・棟11016頂点について、傾斜面から0.1以内かつ屋根幅・奥行き内に収まることを検査。旧版9180頂点が傾斜面の許容外、修正版0頂点。共有box geometryは投下後生成・RESET後も不変。投下後の全ミッション経路あり、ブラウザエラー0。

正面・側面・斜め・遠距離・近距離の5画角で描画確認。python build.py、git diff --check成功。Chromiumのモバイル相当設定を使用。iPhone Safari実機および実機FPSは未検証。
