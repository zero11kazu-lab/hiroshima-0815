# 目的パネル折りたたみ・方位磁針

- 目的パネル右上の「−」で折りたたみ、「目的」で展開。44px以上のタップ領域。
- 表示状態のみ変更。目的本文・距離・対象・ミッション状態は変更しない。目的更新、投下前後の切り替えでも折りたたみを維持する（ページを開き直すと初期状態）。
- `src/navigation-hud.js` の `REVEAL_ON_IMPORTANT_UPDATE` は既定で false。true にすると、主目的本文の変更時だけ `IMPORTANT_UPDATE_SECONDS` 秒表示し、その後元の折りたたみに戻る。
- `WORLD_NORTH = {x:0,y:0,z:-1}`。カメラの実際の前方ベクトルを水平面へ投影して方位盤を回転。中央矢印は画面前方。妻などの位置情報は持たない。
- コンパスは60px・透明度0.6のHTML/CSS。横画面は右下の走行ボタン左、縦画面はその上。会話・イベント・エンディング中は非表示。safe-area対応。
- 入力リスナーを二重追加せず、既存のボタン入力遮断を利用。目的ボタンだけは他の指のスティックを解除しない。
- 更新は既存フレームループ内。追加3Dオブジェクト・描画呼び出し・テクスチャなし。
