# Version 1.4 第3段階 — 被爆後の建物・瓦礫・給水管

## 保全と変更範囲

基準コミット `92fdb68170082dfc3c4bc48e6523e136181e4c5c`（V1.4第2段階）。同じV1.4専用作業ブランチとサイトを使用し、第2段階をGit bundleに保存した。

改良対象は一般建物76棟（住宅37・商店19・長屋15・倉庫5）とミッション2の水源。公共建築3棟の被爆後モデルは維持。投下前建物・配置・樹木配置・人物37人・会話・操作・音声・エンディング・タイトルUIを変更していない。新規描画処理は `src/post-visuals-v14.js` にまとめ、既存生成処理から呼ぶ。

## 被害レベルと外観

既存の距離別被害判定をそのまま使う。全79棟の分類は DESTROYED 17、COLLAPSED 23、HEAVILY_DAMAGED 25、DAMAGED 13、INTACT 1 のまま。

- DESTROYED: 焼けた基礎の輪郭、灰、低い瓦礫、短く焼け残った柱。建物の輪郭はほぼ失う。
- COLLAPSED: 低く崩落した屋根・壁材、焼け柱の切株、木材・瓦・壁片の堆積。
- HEAVILY_DAMAGED: 欠けた壁、露出した柱、狭い屋根残片、壊れた格子、内部が開いた跡。
- DAMAGED: 開口や上部が欠けた壁、欠損屋根、露出した梁・垂木・隅柱、失われた扉、煤と焦げ。
- 既存判定のINTACT 1棟は分類・衝突判定を変えず、見た目のみDAMAGED相当とした。通常モデルの無傷コピーは残さない。

各主要段階に3種の姿・配置差（柱残存数、部材高さ、屋根欠損、倒壊角、瓦礫の位置/大きさ/向きなど）を付ける。既存寸法・回転・座標を使い、新たな建物配置は行わない。ミッション1の既存救助目印の傾いた屋根・柱は同寸法で保持する。

背の高い新しい残存構造は既存の投下後collider内に収める。半壊区域の細い残存壁colliderは元からworld軸に沿っているため、建物回転にかかわらず実際のcollider内へ合わせる。通行可能な建物跡には上端0.28m以下の低い瓦礫を使用。建物の衝突物やダメージゾーンを追加せず、危険ルート・安全ルートを維持する。

## 瓦礫・焼け跡

新しい低い破片は計1,326片（別途304個の基礎部材や残存柱・壁・屋根等）。焼けた木材、瓦の束、土壁/漆喰片、倒れた格子、扉/看板の残片、家財の残片を組み合わせた。旧モデルの汎用瓦礫は7片/棟が中心だった。既存の道路脇42回の低い破片配置処理も保持した。

外観専用の決定的ハッシュで自然な分布を作り、ゲームの乱数・配置抽選に干渉しない。部材を元の建物範囲内へ収め、通路へ高い残骸を新設しない。建物跡に不規則な焦げ・灰の面と基礎を重ねる。面の高さを離してZ-fightingを避け、道路・地面も共有する灰/煤のテクスチャへ投下後だけ切り替える。

火災・煙の配置、密度、描画、ダメージ計算、フォグ、ライティングは変更しない。マサミ最終探索の専用遮蔽・追加火災・煙もそのまま。危険度と経路は固定seedで第2段階と一致する。建物が変わったことによる視界・探索の体感難易度は実機未確認であり、厳密な同一性は主張しない。

## 水汲み場

既存の「破損した住宅給水管」を維持した。断面が開いた管、欠けた管口、継手、簡素な弁、破損した石/モルタル風台座、周囲の壁片・焼け板を追加。少数ポリゴンの連続した水流、濡れた泥/灰、控えめな水たまりで取水箇所を示す。

`waterRoot`、`hydrant.position`、ID `broken-hydrant`、「水を汲む」の対象範囲、抽選、依頼者、収集後の男性の状態/外観、会話、進行条件は変更していない。管口を基準に既存の微小な水流アニメーションを再利用し、流れの上端が管口から離れないようにした。透明な水は1共有material、2mesh。物理水流・粒子・追加音源はない。

判断根拠は既存 `world_1945.json` の水源設定、会話、史料S11「原爆と広島市水道」（広島市水道局、対象1945〜1946年、ページ更新2025-03-31）:
https://www.water.city.hiroshima.lg.jp/site/siryou/9153.html

史料は管や給水栓の破損・漏水・送水を説明するが、このゲームの指定位置での残圧・流出や飲用安全性を証明しない。設備の形・位置・取水イベントはC（ゲーム上の創作）/`gameplay_adjusted` と内部データに記録。歴史資料PDFは変更していない。

被害表現も既存史料S03/S04/S07/S12/S21を参照したゲーム用補完で、個々の建物の実被害の復元ではない。出典の名称・URL・限界は `data/sources.json` を継承。

## 軽量化・負荷比較

同じ箱等の基本geometryと少数材質を再利用し、建物ごとに地面・残存構造・近景破片の3meshへ結合。瓦を1枚ずつ大量生成しない。被爆後の細かな破片は34m（低品質時24m）で非表示、建物全体は既存距離カリングに従う。76棟は1共有Lambert material、共有512×256焼損アトラス1枚。地面用128×128も1共有texture。ミップ込み追加テクスチャ容量は約0.75MiB。透明水は既存更新を利用し、毎フレームの新たな配置判定や物理を追加していない。
