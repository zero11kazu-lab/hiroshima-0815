# V1.4 軌道クリアランスと南側道路接続

基準 c32c613。V1.4専用Siteの既存URLへ更新。旧版と本番には変更しない。

## 原因と変更
軌道の車輪中心/車体外形が明確になったことで、以前から電車通り上にあった生活ユニットと住宅の配置矛盾が確認できた。市役所の端と電柱も干渉。軌道の位置・曲線・車両モデルを変えて避けるのではなく、下記だけ近隣へ移動した。

- 住宅block-34: (10,38) → (11.073,43.394)、約5.5m移動。形状・品質不変。
- 市役所: (-9,-58) → (-11.079,-56.611)、約2.5m移動。形状・品質・既存の史料上の爆心地距離値は不変。実測GIS配置ではない既存舞台図の最小補正。
- 畑/物干し: (20,38) → (20,44)、6m移動。3辺の囲いも一体で移動し、削除なし。
- 電柱: (5.9,37) → (5.9,35)、2m移動。架線の接続と投下後の既存倒れ表現は再配置先を使用。

実際のレール経路各辺から.65mを膨張させたクリアランス帯を配置時に判定。既存の2本の車体幅をカバーする範囲。建物は屋根・軒込みの実メッシュAABB、畑・囲い・小物・柱も実AABB、樹木は幹を検査。橋・市電自身は地物干渉と混同しない。新しい毎フレーム処理なし。

候補位置は既存建物、道路への新規はみ出し、ミッション候補・NPC/マサミの既存経路を避けた近傍検索で選定。データ原本を変更せず、World内部の専用コピーを使用。投下前・後の建物/生活小物の生成とcolliderは同じ修正済みレコードを使用。

## 南側
南は+Z。旧来の南側道路v11-south-mainはz=50〜81まで存在したがtram=falseかつ幅8、路面材も異なり、レール生成対象から外れていた。既存道路を10m幅のtram路面へ統一し、道路・4レールをz=50〜81で連続化。

探索範囲の南端81は維持。その先は同じ道路とレールをz=167までの遠景として接続し、既存最大表示距離78より先に終端が来るようにした。道路脇に26m幅の低負荷な地面を補完。新しい探索区域ではなく、境界手前から終端が見えないための背景。道路・肩で追加2メッシュ程度、軌道は既存1メッシュ/2221三角形のまま。火災・煙・ミッション候補を延長域に新設しない。ここはゲーム用の創作補完(C)であり、当時の南部市街の測量復元とは扱わない。

## 保全と検証
- 実形状によるクリアランス: 投下前の対象地物0件、投下後の建物・生活小物0件。被爆後に既存電柱が傾く表現などは維持。
- 建物の全geometry/UV、原本WORLD_DATAとNPC_DATA一致。樹木位置は全20本とも前版から不変。一般/重要NPC合計37人維持。
- 変更colliderは住宅・市役所・囲い3辺・電柱の6件のみ、寸法・総数不変で各外観の移動先へ追従。幽霊colliderを残さない。
- 南側z=49〜165の14断面でレール上端.04、道路.015をRaycasterで確認。南側徒歩経路60ウェイポイント到達可能。探索外z=82への移動は従来どおり不可。
- 軌道、既存ランドマーク、市電、樹木、NPC100配置サンプル、カメラ、タイトル復帰/再STARTの既存テスト成功。
- WWW-01とEEE-01でミッション1→2→3→マサミ再会、エンディングA/Bのシミュレーション成功。EEE-01の初回はランダムな初期状態で回帰用セットを確保できず、テストが開始できなかった。候補データ/抽選コードは変更せず、テスト乱数を5489からのLCGで固定して対象を確保し再実行。利用可能候補の調査ではM1=64、M2=64、M3=72、EEE-01存在を確認。
- build、JS構文、git diff --check成功。

テストは実Three.js/経路/状態を使うがDOM・WebGLRenderer・音声はスタブ。ブラウザ操作機能がないためiPhone Safari実機での見た目、タッチ、FPS、音声は未確認。比較図は実モデル・実テクスチャのBlenderオフライン描画で、ゲーム/Safariのスクリーンショットではない。
